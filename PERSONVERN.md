# Personvern i Trix

Sist oppdatert 15.11.26.

Trix lagrer det du skriver, på enheten din. Appen sender ikke innholdet ditt
noe sted, og bruker verken informasjonskapsler eller analyseverktøy.

## Filene dine

| Nettleser | Hvor filene ligger |
|---|---|
| Chrome og Edge på datamaskin, Chrome på Android | Mappa trix-data, der du valgte å legge den |
| Safari og Firefox | I nettleseren på enheten din |

Du kan endre og slette filene når du vil. I Safari og Firefox forsvinner
filene hvis du sletter nettleserdata for Trix. Lag en sikkerhetskopi fra
menyen hvis du vil beholde dem.

## Når du åpner Trix

Trix ligger på GitHub Pages. Hver gang du åpner appen med internett,
henter nettleseren appen eller sjekker om det finnes en ny versjon. GitHub
behandler da IP-adressen din og opplysninger om nettleseren etter
[GitHubs personvernerklæring](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
GitHub er et amerikansk selskap.

En lenke du trykker på, åpner nettleseren din. Da gjelder personvernet til
nettstedet.
