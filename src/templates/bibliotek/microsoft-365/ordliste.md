## A

## C

### Copilot Autopilot
Personlig agent i Microsoft Copilot som arbeider i bakgrunnen med Microsoft 365 og Work IQ, innenfor rammene du og organisasjonen setter. I privat forhåndsvisning.

## D

### Data Security Posture Management (DSPM)

Også: DSPM

### Dokumentbehandling for Microsoft 365 (document processing)

Også: SharePoint Premium, Microsoft Syntex, SharePoint Syntex
#m365 #ki #tjeneste

## F

#m365 #ki #begrep
